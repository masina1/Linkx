# Promo assets

Marketing/store graphics for Linkx. Each PNG is built from the matching HTML source (pure HTML/CSS, inline vector icon — no dependencies), so you can tweak the `.html` and re-render.

| Image | Size | Source | Use |
|---|---|---|---|
| `linkx-marquee-1400x560.png` | 1400×560 | `banner.html` | Chrome Web Store marquee promo tile |
| `linkx-feature-1280x800.png` | 1280×800 | `feature.html` | Store screenshot / feature graphic |
| `linkx-promo-440x280.png` | 440×280 | `small.html` | Chrome Web Store small promo tile |

## Re-rendering

Open the `.html` in a browser sized to the target dimensions and screenshot the viewport, or use any headless-Chrome screenshot tool at the exact width×height above. The layouts are fixed to those dimensions.
